首次使用配置

约 3 分钟

在多维表格中挂载脚本

打开「测试盘点」多维表格 → 脚本 → 新建 AirScript 脚本，把项目目录下 airscript.js 的内容全部粘贴进去。

开启 Webhook 并复制凭据

在脚本编辑器里开启 Webhook：复制「脚本 webhook 地址」和「脚本令牌」。

填写 config.json

把 webhook 地址和令牌填入 pandian-web/config.json，并将 "mock": true 改为 false，重启 node server.js。

确认两张数据表

「货品资料」表需含列：产品编号 / 产品名称 / 货品条码；「盘点数据」表建议包含：库位 / 条码 / 数量 / 生产日期 / 到期日期 / 产品编号 / 产品名称（缺列不会报错，对应字段会被跳过）。

同条码多品名规则

货品资料中同一基础条码会用 -1、-2 等后缀区分不同品名，例如 6975983219135 与 6975983219135-2。本页按去掉后缀后的基础条码匹配：

· 匹配到 1 个品名 → 自动带出，直接提交；
· 匹配到多个品名 → 弹窗列出全部候选，点选后自动填入；
· 未匹配到 → 红色提示，请先在货品资料表中登记该条码。
